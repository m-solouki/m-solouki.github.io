### Path 1: Dependable Software and Functional Safety

My primary research focuses on developing advanced software solutions to enhance system reliability and ensure functional safety, particularly for automotive and industrial applications compliant with the ISO 26262 standard. Key contributions in this area include:

* **Fault Tolerance:** Developing Software-Implemented Hardware Fault Tolerance (SIHFT) methods to detect Control Flow Errors (CFEs) caused by Random Hardware Failures (RHFs) in embedded systems.
* **Execution Efficiency:** Integrating CFE detection techniques directly into model-based software design to significantly improve real-time execution efficiency.
* **Safety Compliance:** Proposing a comprehensive classification scheme for permanent hardware faults to streamline and aid in ISO 26262 compliance.

### Path 2: Secure Memory Systems and Reliable Processing-in-Memory for AI

My current and upcoming research explores the reliability, security, and fault-tolerance of next-generation memory architectures, focusing specifically on hardware accelerators for Artificial Intelligence. This research path encompasses:

* **Robust Compute-in-Memory (ROBUST-CIM):** Developing comprehensive fault-tolerance strategies for memristive compute-in-memory (CIM) neural network accelerators. This involves leveraging machine learning-based fault mitigation techniques, such as LSTM-based power profiling and iterative pruning, to ensure reliable execution in advanced hardware.
* **Memory Security and DRAM Reliability:** Collaborating on secure memory systems to build highly efficient Processing-in-Memory (PIM) architectures. This work aims to bridge the gap between high-performance AI execution and critical hardware security, ensuring reliable operations in modern computing environments.
